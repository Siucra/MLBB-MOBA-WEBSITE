# Mobile Legends: Bang Bang Fan Page

A simple fan-made website dedicated to **Mobile Legends: Bang Bang (MLBB)**, one of the most popular mobile MOBA games of the past decade.

> **Disclaimer:** This is an unofficial fan project. It is not affiliated with, endorsed by or sponsored by Moonton or ByteDance. All game names, characters and assets belong to their respective owners.

🔗 **Live Demo (using netify):** https://moba-mlbb-fan.netlify.app/

---

## About the Project

This page is a beginner-friendly tribute to MLBB. It was built to practice combining  HTML, traditional CSS, Tailwind CSS and JavaScript in a small project.

## Features

- **Hero Roles:** Overview of each hero type (Tank, Fighter, Assassin, Mage, Marksman, Support) and what they do in a match.
- **Hero Release Timeline:** Heroes listed in chronological order by release date, each with a short description.
- **Battle Preparation:** Breakdown of the components you set up before a match (emblems, battle spells and item builds).
- **Game Modes & Maps:** Explanation of the different game modes and the maps they're played on.
- **Fun Trivia:** A trivia section at the end of the page.
- **Responsive Design:** Layout adapts to desktop, tablet, and mobile screens.

## Tech Stack

| Technology | Purpose |
